The tour导览

Follow the line沿着这条线走一遍

Eight stops. One map.八站，看懂这张图。

01

The problem问题

More agents: you lose track of them, they lose track of each otheragent 一多，你看不清它们，它们也看不见彼此

Claude Code here, Codex there, one more on the workstation. A day later nobody knows who did what, and every new agent starts by asking you.

Claude Code 一个窗口，Codex 一个窗口，工作站上还跑着一个。过一天，谁做了什么就说不清；每个新 agent 都得从头问你。

02

For you给你看

One session, one line. Who did what, at a glance一个会话一条线，谁做了什么一眼看懂

Dark stations are yours, coloured ones the agents'. Forks and merges are drawn like git. Hooks draw it; you do nothing.

深色站点是你的指令，彩色是 agent 的产出，分叉合并像 git。hooks 自动画，你什么都不用做。

03

For agents给 agent 读

A new agent catches up in seconds新开的 agent，几秒接上进度

Over MCP, Claude Code and Codex read the same line you see: the goal, the to-dos, every result. No more explaining it all again.

Claude Code、Codex 通过 MCP 读你看到的同一条线：目标、待办、每个结果。不用你再讲一遍。

04

Goals and to-dos目标和待办

One list for you and your agents人和 agent 共用一份清单

You write the goal and the to-dos; agents tick them off and sign it. Say "dispatch" and every line gets to work.

你写目标和待办，agent 做完自己勾，标着是谁勾的。说一句「分派」，每条线都开工。

05

What changed改了什么

"Done," says the agent. The diff is one click awayagent 说做完了？diff 就在旁边

A commit station lists its files. Click for the diff, or compare with any earlier station. Straight from git.

提交站点列出改过的文件，点开看 diff，还能和任意更早的站点对比。直接读 git。

06

Retro复盘

Twelve rounds this time. One round next time这次来回十几轮，下次一轮就过

Retro finds the work that took the most back-and-forth, where it got stuck, and turns it into a rule for CLAUDE.md, AGENTS.md or memory, written only when you say so.

点「复盘」，找出来回最多的事、卡在哪，提炼成规矩；你点「写入」才写进 CLAUDE.md、AGENTS.md 或长期记忆。

07

Machines and phone多台电脑和手机

Every machine on one map, your phone too几台电脑一张图，手机上也能记

Machines sync through your private git repo, records carry the machine's name, and a to-do can go to a given machine. On the phone, open it over Tailscale.

几台电脑经私有 git 仓库同步，记录标着机器名，待办能指定交给哪台。手机经 Tailscale 打开，随手记、随手改。

08

On your computer, at about 1% of the tokens跑在你的电脑上，只占约 1% 的 token

Node.js

只要 Node.js 18.17+，不用 npm install；数据留在 ~/.trace-canvas。

MIT

Open source, free to use.

开源，免费用。

~1%

About 1% of a session's tokens, however big the map gets. The hooks run outside the model.

约占会话 token 的 1%，图再大也不涨。hooks 在模型之外运行。

Install安装

Paste this into Claude Code (or Codex):把这句话贴给 Claude Code（或 Codex）：

Install Trace Canvas: clone https://github.com/CallSymmetryEcho/trace-canvas.git into ~/trace-canvas, then run node ~/trace-canvas/bin/trace-canvas.mjs setup --user (add --agents codex if Codex is installed).

安装 Trace Canvas：把 https://github.com/CallSymmetryEcho/trace-canvas.git 克隆到 ~/trace-canvas，然后运行 node ~/trace-canvas/bin/trace-canvas.mjs setup --user（装了 Codex 的话加上 --agents codex）。

Or by hand:或者手动：

git clone https://github.com/CallSymmetryEcho/trace-canvas.git ~/trace-canvas
node ~/trace-canvas/bin/trace-canvas.mjs setup --user

Then start a new Claude Code session and type /trace-canvas put all my sessions on the canvas. It puts this project's past sessions on the map and opens it at http://localhost:4777/; from then on every new session lands on it by itself.

然后新开一个 Claude Code 会话，输入 /trace-canvas 把现在所有的会话展示在画布上。它会把这个项目过去的会话放上地图，并在 http://localhost:4777/ 打开；之后每个新会话都会自动出现在上面。
